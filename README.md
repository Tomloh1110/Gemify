## 🚀 The Vision
Gemify is not just another task list; it is a **Structured AI Evolution Engine**. As an Industrial Statistics student, I designed Gemify to solve the "Motivation Gap" in self-directed learning. By leveraging **Google Gemini 3 Flash Preview**, Gemify deconstructs impossible career ambitions into a rigorous, 10-stage technical roadmap。

## ✨ Key Features (The "Winner's Circle" Upgrades)
- **🛡️ Anti-Cheat Evidence System**: To maintain high-integrity learning, users must submit "Proof of Work" (summaries or links) to verify task completion before claiming XP.
- **📈 n-Stage Sequential Evolution**: A deeply-mapped learning journey scaling from "Neural Mapping" (Beginner) to "System Mastery" (Expert).
- **🎓 Professional Academy Integration**: Dynamic resource sourcing from high-authority platforms like **W3Schools, GitHub, and Coursera**, moving beyond simple video links.
- **🛠️ Integrated Toolbox**: Automatically recommends the exact software or apps (e.g., VS Code, CapCut, Blender) required for each specific stage.

## 🏗️ Engineering Excellence
### 1. High-Performance CI/CD Pipeline
Instead of relying on standard, generic deployment models, I optimized a custom **GitHub Actions workflow**.
- **Efficiency**: Reduced deployment overhead by **57%**.
- **Speed**: Achieved a record-breaking **17-19s total deployment time** from commit to live.

### 2. Enterprise-Grade API Security
Operating in a public repository required a robust security posture:
- **Domain Lock**: The API is strictly secured via **Referer Restrictions** in the Google Cloud Console, whitelisting only the `tomloh1110.github.io` domain.
- **Zero-Config for Judges**: To respect judges' time, the engine is pre-configured and domain-secured. No personal API keys or environment setups are required to test the full logic.

## 🧪 Tech Stack
- **Core Engine:** Google Gemini 3 Flash Preview.
- **UI Architecture:** Tailwind CSS with a custom **Neon Cyberpunk** design language.
- **State Management:** Persistent `localStorage` for cross-session evolution tracking.
- **Icons:** Lucide-React for dynamic role-based visual feedback.
